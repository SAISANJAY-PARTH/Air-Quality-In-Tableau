# Air-Quality-In-Tableau
India Air Quality Data Visualization Using Tableau

In this project, I used Tableau Desktop to perform data visualization and storytelling on the India Air Quality dataset from Kaggle.

Objective
My goal was to practice data storytelling, visualization, and dashboard creation using Tableau. I also wanted to share my work so it can help others generate ideas for their own visualizations.

About the Dataset
Dataset link: https://www.kaggle.com/shrutibhargava94/india-air-quality-data
This dataset is a combined and mostly cleaned version of the Historical Daily Ambient Air Quality Data released by the Ministry of Environment and Forests and the Central Pollution Control Board under the National Data Sharing and Accessibility Policy (NDSAP). It contains air quality data across multiple years and states.

Key Columns:
Stn_code (Dimension): Station code for states or cities
Sampling_Date (Dimension): Specific month and air quality report date
State (Dimension): Name of the state
Location (Dimension): Name of the city
Agency (Dimension): Authority responsible for collecting the data
So2 (Measure): Sulphur Dioxide levels
No2 (Measure): Nitrogen Dioxide levels
Rspm (Measure): Respirable Suspended Particulate Matter
Spm (Measure): Suspended Particulate Matter
location_monitoring_station (Dimension): Exact location where air quality was measured
pm2_5 (Dimension): PM 2.5 levels
Date (Dimension): Monthly dates from 1987 to 2000
Type (Dimension): Zone type (e.g., industrial, residential)

Data Cleaning
The dataset was mostly ready for analysis, so it required minimal preprocessing. I performed basic cleaning such as renaming the Area column to Area Type and correcting spelling errors in city and state names. These adjustments were done using Microsoft Excel.https://www.kaggle.com/shrutibhargava94/india-air-quality-data
